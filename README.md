# Meesta Chess

A lightweight autochess-style prototype built as a single-page web app.

## What is included

- Shop and gold economy
- Bench for purchased units
- Board deployment for player units
- Auto-combat against an enemy team
- Simple state-driven UI designed for future expansion

## Run locally

Open [index.html](index.html) in a browser, or serve the folder with a static server such as:

```bash
python -m http.server 3000
```

Then visit http://localhost:3000.
